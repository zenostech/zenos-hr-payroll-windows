# ZENOS HR & Payroll for Windows

This repository holds the Windows setup download. The application source stays in the private repository `zenostech/zenos-hr-payroll`.

The setup file is `ZENOS-HR-Payroll-Setup-x64.exe` on the [v1.0.0 release](https://github.com/zenostech/zenos-hr-payroll-windows/releases/tag/v1.0.0).

It is an unsigned per-user installer for 64-bit Windows 10 and 11. It was packed on a Linux build machine and has not been launched on Windows from that machine. Windows may show a warning before it runs. The installer includes the application, PHP, and MariaDB, so those do not need a separate install.

The same release also includes `zenos-hr-payroll.zip` for WordPress.
